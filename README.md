# ARENA course

This repository contains my solutions to the exercises from the [ARENA course](https://www.arena.education/curriculum).
I finished the course at my own pace and found it very helpful for learning Mechanistic interpretability in AI/ML concepts. The solutions to the exercises are implemented in Python, using Jupyter Notebooks.

The intention of this repository is to share my learning journey and provide reference implementations for others interested in the same topics.
Feel free to explore the notebooks and use them as a resource for your own learning!

Additional resources:
- http://deeplearning.stanford.edu/tutorial/


## Repository Structure
- `notebooks/*.ipynb`: Jupyter Notebooks containing solutions to the exercises from the ARENA course.
- `src/`: Modular production code implementation of theory developed in the notebooks.

## Running Demo transformer model

```bash
uv run src/gpt/main.py
```
